# BiGGeR · Demo de gestión de plazas

Prototipo de Agallart Digital para revisar la organización de plazas del taller.

- Grupos regulares de hasta cinco alumnos.
- Altas y bajas manuales, lista de espera y cambios de grupo.
- Buscador de alumnos, historial de movimientos y calendario.
- Eventos informativos con inscripciones a cargo de los talleristas.

Todos los datos, alumnos, horarios y eventos son ficticios. Los cambios se reinician al recargar. No realiza reservas, no envía mensajes y no almacena datos reales. El presupuesto se comparte por separado.

Abre `index.html` en un navegador. La versión final requerirá autenticación y almacenamiento persistente.
